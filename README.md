# Revolution9ine — Website Starter

## What this is
A simple multi-page static website you can upload to Netlify.

## Pages
- index.html (Home)
- shop.html (Shop)
- lore.html (Lore)
- about.html (About)
- contact.html (Contact)

## Edit styling / scripts
- assets/css/style.css
- assets/js/main.js

## Deploy to Netlify
Netlify → Add new site → Deploy manually → drag-and-drop the folder (or zip).
